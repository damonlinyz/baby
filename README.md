# 爸爸在呢

以爸爸为统筹核心的家庭孕产协作助手。保留暖橙风格界面，包含网页自用端、微信小程序源码、HTML5+ App 入口和共享后端。

**当前是开发中的自用版本，不是已完成生产验收的正式产品。** 原静态演示保存在 `demo/`；正式页面使用后端账户和数据库，不沿用演示中的虚构身份。

## 本机运行

需要 Python 3.9+；支付协议适配器另外需要 Node.js 22+。核心服务使用 Python 标准库，日期计算需要系统 IANA 时区数据库；缺少时区数据的系统需安装 `tzdata`。

```sh
PYTHONDONTWRITEBYTECODE=1 PORT=8766 python3 backend/server.py
```

打开 `http://127.0.0.1:8766`，注册个人账号，再创建家庭或用一次性邀请码加入。每名家人使用独立账号。默认只监听本机，不直接提供跨设备访问。

数据库自动建立在 `private/baba.sqlite3`，并创建独立的 `private/baba.sqlite3.deletions.sqlite3` 删除记录，该目录已排除在 Git 之外。不要将数据库、密码、模型密钥或支付证书上传到仓库。保存重要资料前自行做好备份；当前 SQLite 数据没有应用层字段加密。

## 已编写的功能

- 账号注册、登录、会话、CSRF 校验，家庭成员、一次性邀请、角色权限。
- 家庭任务、分工、自定义事项、状态更新、待妈妈确认与批准/退回、版本冲突检查。
- 按天/周重复的普通家务、独立实例、单次改期与停止，保留完成历史；负责人离开或删除账号时停止对应安排。
- 网页与小程序家庭修改的弱网重试和结果核对、会话失效清理、前台授权复查；旧账号或较旧读取结果不会覆盖当前视图。
- 待产物品管理与导出、预约编辑改期与站内提醒、普通任务提醒开关；旧安排提醒取消与新安排去重。
- 妈妈本人建档、敏感健康日期独立授权、孕次日期修订、分娩、结束、暂停与归档。
- 修改密码、一次性恢复码找回、小程序重新验证已绑定微信后改密或注销；安全变更退出全部设备。
- 网页密码确认删除账号，清理关联健康资料与派生记录；撤权后读取、导出与提醒重新校验，普通动作支持内容绑定的幂等重试。
- 孕次事件历史、修订前后快照和站内通知 Outbox；原始末次月经日期与预产期估算、医生确认日期保护；服务端统一孕周、产后日龄和日历周年计算；网页与小程序时间轴变更预览，确认后保存并检查并发冲突。
- 误录分娩补偿事件及原始历史保留；多胞胎独立出生日期与状态、宝宝资料单独共享授权；未确认、住院或离世时停止成长纪念类任务，妈妈产后照护独立保留。
- 家庭 IANA 时区设置、日期冲突校验与提醒重算；启用二次确认后，修改时区遵循妈妈确认流程。
- 84 项可选生活任务库，统筹者按需选用和分配，不自动推算健康安排；完成记录的家庭点赞、留言和删除，按当前权限筛选。
- 知识按当前角色/阶段/个人地区筛选，家人封闭策展；来源链接、许可、适用范围与有效期独立版本保存，打开正文及 AI 交付重查范围。
- 生活准备模板与步骤、当前知识关联、实时每周报告、每人独立的自动周简报与历史快照；管理员网页知识发布/撤回/有效期管理。
- 四组 15 枚个人徽章、当天参与记录、完成归属凭据、独立宝宝授权的可选纪念及安静展示。
- 分类提醒、静默、合并、每日上限；可选一次性微信订阅软件链路，默认关闭，未知结果不盲目重发。
- 通用模板 PNG 海报、网页二维码和默认关闭的真实小程序码适配；不含家庭资料或私人分享令牌。
- 不含家庭信息的公开模板、选择并确认的限时私密清单、最小字段、撤销与逐次权限/版本核验。
- 本人 AI 成功/处理中/近 24 小时用量、共享周期的问答/简报独立剩余额度；任务与物品的通用问题入口，不自动附带私人标题或备注。
- 本人历史模型问答（180 天）、正文删除、独立配额的可选周简报增强；自动增强须主动同意，仅发送普通任务/物品数量与公开生活知识。
- 私密使用问题工单、管理员回复、本人撤回与 180 天正文清理，恢复不复活已撤回问题；系统管理员队列状态与站内失败通知的幂等安全重排。
- AI API 配置入口和有效生活知识检索，模型请求恢复、占额租约与交付前鉴权；生成式医疗问答保持关闭。
- 微信支付与支付宝订单适配、签名与验签、支付回调、查单、交易唯一账本、退款响应核对与幂等处理代码。
- 可选异地密文同步、完整回读校验、独立删除副本、通用故障 Webhook 和定时模板；尚未配置实际存储或接收人。
- GitHub Actions 回归及干净 Git 提交的可复现发布打包工具，附 APK 须先校验签名和包名/版本；尚无正式安装包。
- 加密备份任务、完整/删除记录独立保留、过期和失败检查、解密与删除重放演练；提供尚未安装的 systemd 定时模板。
- 重复买断收款不重复发权益或赠送 AI，自动建立待核验售后单；本人订单/售后状态、网页系统管理员退款核对和查询入口。规则见 [重复收款处理](docs/支付重复收款处理.md)。

## 客户端与渠道

| 客户端 | 源码 | 状态 |
|---|---|---|
| 网页 | 根目录 HTML/CSS/JS | 可连接本机后端 |
| 微信小程序 | `clients/weapp/` | 原生源码，可导入微信开发者工具；需填写 AppID 和合法 HTTPS 服务域名，尚未完成真机验收 |
| App | `clients/app/` | HTML5+ 原生入口，复用服务端页面及原生支付桥；需配置 DCloud 标识、包名、微信 AppID 和签名后打包，尚无正式安装包 |

微信小程序只使用微信支付，App 适配微信支付和支付宝。iOS 数字商品的支付路径尚未完成商店核验，目前客户端阻止外部支付。不能假设 Android 的支付方案可直接用于 iOS。

## 外部服务

所有密钥从**服务端环境变量**读取；当前程序不会自动加载 `.env`。可参考 `.env.example` 配置进程环境，不要把真实配置提交到 Git。

- AI：`AI_BASE_URL`（HTTPS、OpenAI 兼容接口基础地址）、`AI_API_KEY`、`AI_MODEL`。未配置时只返回本地已发布生活知识，不能宣称模型已接入。
- 可选小程序码：`WX_POSTER_ENABLED=1` 及微信登录配置，正式版固定通用模板落地；默认关闭。
- 微信登录：`WX_APP_ID`、`WX_APP_SECRET`。
- 可选微信订阅：`WX_NOTIFY_ENABLED=1`、已审核的 `WX_REMINDER_TEMPLATE_ID`（通用 `thing1` 模板）及上述微信配置，还需小程序逐次同意；默认关闭，未做真机送达验收。
- 微信支付：商户号、商户证书序列号、私钥文件、公钥 ID、公钥文件、API v3 密钥、AppID 和通知地址。
- 支付宝：应用 ID、收款主体 ID、应用私钥文件、支付宝公钥文件和通知地址；当前为公钥模式。
- `PAYMENTS_ENABLED=1` 才允许进入下单；AI 套餐还需 `AI_SALES_APPROVED=1`。这些开关不替代真实支付验收。
- `SERVICE_MODE=paid` 使用付费 AI 权益与周期配额；默认自托管模式使用每日自用调用上限。
- `ADMIN_USER_ID` 指定系统内容、售后、问题工单与队列管理员；家庭统筹者不会自动得到系统管理权限。

没有配置时接口会明确拒绝支付，不生成假成功。尚未进行真实商户扣款、退款、证书轮换或 App 支付联调。

## 验证

```sh
PYTHONDONTWRITEBYTECODE=1 python3 -m unittest discover -s tests -v
node --check app.js
node --check backend/payment-crypto.mjs
```

测试使用临时数据库和合成身份。支付权益测试检查领域逻辑，不代表真实渠道联调通过。正式公开前仍需内容专业审校、完整隐私与安全审计、备份恢复、平台资质、端到端客户端验收及支付联调。
