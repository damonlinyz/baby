# 爸爸在呢

以爸爸为统筹核心的家庭孕产协作助手。保留暖橙风格界面，包含网页自用端、微信小程序源码、HTML5+ App 入口和共享后端。

**当前是开发中的自用版本，不是已完成生产验收的正式产品。** 原静态演示保存在 `demo/`；正式页面使用后端账户和数据库，不沿用演示中的虚构身份。

## 本机运行

需要 Python 3.9+；支付协议适配器另外需要 Node.js 22+。核心服务无第三方 Python 依赖。

```sh
PYTHONDONTWRITEBYTECODE=1 PORT=8766 python3 backend/server.py
```

打开 `http://127.0.0.1:8766`，注册个人账号，再创建家庭或用一次性邀请码加入。每名家人使用独立账号。默认只监听本机，不直接提供跨设备访问。

数据库自动建立在 `private/baba.sqlite3`，该目录已排除在 Git 之外。不要将数据库、密码、模型密钥或支付证书上传到仓库。保存重要资料前自行做好备份；当前 SQLite 数据没有应用层字段加密。

## 已编写的功能

- 账号注册、登录、会话、CSRF 校验，家庭成员、一次性邀请、角色权限。
- 家庭任务、分工、自定义事项、状态更新、待妈妈确认与批准/退回、版本冲突检查。
- 待产物品管理与导出、预约与站内提醒、普通任务提醒开关。
- 妈妈本人建档、敏感健康日期独立授权、孕次日期修订、分娩、结束、暂停与归档。
- 生活准备模板、知识阅读与版本、基础简报、家庭报告、可见数据导出。
- AI API 配置入口和一般生活知识检索；生成式医疗问答保持关闭。
- 微信支付与支付宝订单适配、签名与验签、支付回调、查单、权益账本及退款处理代码。

## 客户端与渠道

| 客户端 | 源码 | 状态 |
|---|---|---|
| 网页 | 根目录 HTML/CSS/JS | 可连接本机后端 |
| 微信小程序 | `clients/weapp/` | 原生源码，可导入微信开发者工具；需填写 AppID 和合法 HTTPS 服务域名，尚未完成真机验收 |
| App | `clients/app/` | HTML5+ 原生入口，复用服务端页面及原生支付桥；需配置 DCloud 标识、包名、微信 AppID 和签名后打包，尚无正式安装包 |

微信小程序只使用微信支付，App 适配微信支付和支付宝。iOS 数字商品的支付路径尚未完成商店核验，目前客户端阻止外部支付。不能假设 Android 的支付方案可直接用于 iOS。

## 外部服务

所有密钥从**服务端环境变量**读取；当前程序不会自动加载 `.env`。可参考 `.env.example` 配置进程环境，不要把真实配置提交到 Git。

- AI：`AI_BASE_URL`（HTTPS、OpenAI 兼容接口基础地址）、`AI_API_KEY`、`AI_MODEL`。未配置时只返回本地已发布生活知识，不能宣称模型已接入。
- 微信登录：`WX_APP_ID`、`WX_APP_SECRET`。
- 微信支付：商户号、商户证书序列号、私钥文件、公钥 ID、公钥文件、API v3 密钥、AppID 和通知地址。
- 支付宝：应用 ID、收款主体 ID、应用私钥文件、支付宝公钥文件和通知地址；当前为公钥模式。
- `PAYMENTS_ENABLED=1` 才允许进入下单；AI 套餐还需 `AI_SALES_APPROVED=1`。这些开关不替代真实支付验收。
- `SERVICE_MODE=paid` 使用付费 AI 权益与周期配额；默认自托管模式使用每日自用调用上限。
- `ADMIN_USER_ID` 指定系统内容与售后管理员；家庭统筹者不会自动得到系统管理权限。

没有配置时接口会明确拒绝支付，不生成假成功。尚未进行真实商户扣款、退款、证书轮换或 App 支付联调。

## 验证

```sh
PYTHONDONTWRITEBYTECODE=1 python3 -m unittest discover -s tests -v
node --check app.js
node --check backend/payment-crypto.mjs
```

测试使用临时数据库和合成身份。支付权益测试检查领域逻辑，不代表真实渠道联调通过。正式公开前仍需内容专业审校、完整隐私与安全审计、备份恢复、平台资质、端到端客户端验收及支付联调。

## 项目结构

```text
clients/weapp/    微信客户端源码
clients/app/      HTML5+ App 入口
web root          网页与原生支付桥
 tests/           领域、HTTP 与权益测试
 demo/            原始静态演示
```
