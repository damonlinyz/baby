## 已确认的产品基线

- 爸爸统筹；妈妈二次确认可配置；其他成员学习与执行。
- 个人敏感健康信息授权始终由本人控制，不因家庭管理员角色而转移。
- 完善正常孕期、日期修订、提前分娩、妊娠结束、暂停与归档等状态。
- AI 采用医疗安全工程、知识版本与溯源；不能用免责声明代替安全约束。
- 生产设计包含服务端权限、任务实例、支付与权益账本、内容版本及审计。
- ¥128 买断核心产品与核心更新，赠首月 AI；后续 AI 独立收费。
- 不安排市场验证，以开发者本人重度自用优先，分阶段开发。
- 微信小程序使用微信支付；App 适配微信支付和支付宝，具体开放受平台政策和资质约束。

## 定稿与实现的区别

v1.3 是产品需求与设计基线，不代表全部功能已经开发或上线。方案中明确为拟定值的 AI 续费价格、配额及部分默认参数，仍需在实施或开售前锁定，不因本次归档变为已确认商业承诺。

现有代码采用本机网页、Python/SQLite 共享后端、原生微信小程序源码和 HTML5+ App 入口，尚未完成方案中的 CloudBase/Taro 生产交付。当前实现情况以仓库根目录 README 为准，不能以设计文档替代验收记录。

密码、密钥、支付证书、真实健康信息及本机数据库不属于项目文档，禁止提交到仓库。
