# 开发任务清单

更新日期：2026-10-22。依据产品方案 v1.3、渠道补充和当前代码；完成标准以实际测试与验收为准。

## 当前判断

已有可运行的 Python/SQLite 后端、网页、小程序源码与 App 入口。账号、家庭协作、健康授权、清单、预约和支付领域代码已存在。当前测试覆盖部分关键流程，不能据此认定完整方案交付。优先完善家庭自用的可靠性，再扩展内容、商业化与发布。

## 本轮完成：确认流程可靠性

- 确认过期时，将版本仍匹配的待确认任务/物品恢复为进行中，可重新提交；读取家庭状态和后台调度均执行过期整理。
- 模板重排仅在实际日期变化时修改任务；改期取消旧确认并恢复进行中。暂停等不改变日期的事件不会使确认因版本变化失效。
- 确认策略改变时取消旧待确认申请，相关事项恢复进行中；审批时校验策略版本、事项版本与待确认状态。
- 单独修改家庭名称不增加确认策略版本；敏感日期任务审批时重新检查查看权限。
- 新增三项领域回归测试，完整测试共 22 项通过；网页与支付适配器 JavaScript 语法检查通过。

## 第二轮完成：删除、撤权与并发可靠性

- 网页设置与未加入家庭的欢迎页增加删除账号入口，输入密码并确认删除范围后提交。仍担任任一家庭统筹的账号必须先完成转交；服务端同步校验。
- 删除健康资料本人账号时，清理孕次、关联预约、宝宝记录、敏感日期模板任务、确认和提醒；普通家庭任务解除孕次关联，家庭仍可读取且调度器不再访问悬空记录。会话随账号删除失效。
- 查看权限撤回后，代录人也不能继续读取自己录入的预约；导出、孕次列表、敏感任务、确认和提醒均按当前权限过滤。预约修改单独检查代录授权；调度器发送前复查查看权限。
- 统筹转交只保留最新待接受申请，接受前校验发起人仍是当前有效统筹；成员离开或被移除会取消相关转交与确认。转交完成撤销旧统筹代录授权与未使用邀请，新统筹不会自动继承健康授权。
- 普通动作请求使用独立的 `command_requests` 表，绑定请求号、家庭、动作和参数摘要；相同内容重试返回原结果，内容冲突返回 409。旧版未保存绑定信息的请求号返回 409，客户端可刷新后以新请求号提交。
- 删除资料时清除受影响家庭的命令缓存结果，同时保留去重标记，防止重试重建已删除数据；这些历史请求再次提交返回 409。
- 新增 15 项测试，包含两个线程同时创建任务重试、同时接受转交，以及 HTTP 撤权导出、删除与会话失效；完整 37 项测试通过，网页 JavaScript 语法和差异空白检查通过。尚未进行浏览器交互或小程序/App 真机验收。

### 当前边界

本轮清理活动数据库里的上述资料与引用；订单权益账本和必要业务审计保留。既有备份的删除重放与恢复演练仍待实现，不能将当前账号删除等同于备份清理完成。其他客户端已加载的页面与自行保存的数据无法通过服务端读取鉴权追回。微信登录自动创建的账号尚无密码自助设置，因此本轮密码删除入口主要服务于账号密码用户。

## 第三轮完成：统一日期计算与变更预览

- 增加 `backend/dates.py`，使用家庭 IANA 时区（默认 Asia/Shanghai）和日历日期计算孕周、内容阶段、产后日龄与宝宝月龄。0 周有效，负孕龄拒绝；超过预产期不自动分娩。周岁按日历周年计算，2 月 29 日在非闰年以 2 月最后一天作为周年日。
- 网页与小程序统一使用服务端返回的 `pregnancy.timeline`，不再分别计算孕周；严格校验日期格式与 EDD 来源。
- 增加 `POST /api/pregnancy/preview`，校验当前成员、健康查看与代录权限；在数据库保存点内模拟变更并回滚，不保存任务、通知、宝宝或审计副作用。
- 网页与小程序保存时间轴变更前先展示新增、改期、取消待办和取消提醒的数量与明细，并说明保留的已完成记录与固定预约数。确认提交携带预览指纹；预览后家庭数据发生变化时返回 409，需重新预览。
- EDD 重排取消旧日期的未读任务提醒；分娩或妊娠结束取消孕期待办时同步使其待确认申请失效，保留已完成和已跳过历史。
- 完整 51 项自动测试通过，含日期边界、只读预览、并发预览失效、通知取消与 HTTP 保存流程；网页和小程序 JavaScript 语法检查通过。使用 Chromium 与临时合成账号验证了网页登录、服务端孕周显示、只读预览和确认保存；小程序真机尚未验收。

### 兼容与剩余范围

旧客户端仍可直接提交原有 `pregnancy.event`，新网页与小程序均走预览确认流程；预览指纹不是强制旧客户端升级的接口条件。LMP 原始日期录入与自动估算 EDD、完整的补偿事件/Outbox、多胎不同结局和家庭时区修改界面仍待后续实现，当前不能称为完整孕次状态机交付。

## 第四轮完成：预约提醒与内容版本管理

- 网页与小程序提供预约编辑、改期、完成、取消；仍由录入人且具备当前代录授权的账号修改，版本冲突返回 409。
- 预约与任务提醒使用安排修订号去重；改期、重新打开、分工改变时取消旧未读提醒并为新安排建立独立去重键。完成和关闭普通任务提醒会取消相关未读提醒。
- 调度器按家庭时区处理当天及将到期安排，不补发已经过期的预约/任务；暂停后已取消的预约提醒不会因恢复重复发送。一般家务提醒不因缺少健康查看授权而隐藏，敏感日期提醒继续鉴权。
- 系统管理员在网页协作设置内管理生活知识的草稿、发布、撤回、到期日；每次保存保留独立版本，普通家庭统筹没有系统内容管理权限。
- 有效期包含截止当天，过期/撤回/医疗或格式无效的内容不进入列表和 AI 检索。模型无有效参考时不调用；交付与缓存重放前复查引用版本，撤回时拒绝旧答案且释放生成用量。
- 完整 64 项自动测试通过；JavaScript 语法检查通过。Chromium 验证覆盖预约编辑改期、管理员发布与撤回。真实模型、外部推送、小程序真机尚未验收。
