# 异地备份与发布工具

更新：2026-10-29。本轮交付工具、模拟 HTTP 测试、定时模板及本地打包验证，未配置真实存储/告警接收人，未部署生产定时器、发布商店版本或上传正式安装包。

## 加密副本异地同步

在现有 [加密备份任务](备份自动任务.md) 成功后，使用 `backend/offsite.py` 复制已校验的密文批次。目标存储必须支持带可选 Bearer 认证的 HTTPS PUT/GET/HEAD；当前没有原生 S3 SigV4 适配器，S3 等服务需要提供兼容入口或另行适配，不能直接把 bucket 名当端点。

服务端进程读取以下环境变量，不自动加载 `.env`。实际值只在可信主机配置，权限设为 0600：

```text
BABA_OFFSITE_URL=https://storage.example.invalid/baba-full
BABA_OFFSITE_TOKEN=
BABA_BACKUP_ALERT_URL=https://monitor.example.invalid/baba
BABA_BACKUP_ALERT_TOKEN=
```

完整副本与独立删除记录建议使用不同存储账号/位置，分别放入 `offsite-full.env` 和 `offsite-ledger.env`。URL 不接受明文 HTTP、内嵌账号密码、查询参数或片段；拒绝重定向，保持 TLS 校验。存储和告警使用独立令牌，不能将备份令牌发给告警接收方。

```sh
python3 backend/offsite.py sync --db private/baba.sqlite3 --directory backups/encrypted --kind full
python3 backend/offsite.py sync --db private/baba.sqlite3 --directory backups/encrypted --kind ledger
python3 backend/offsite.py check --db private/baba.sqlite3 --directory backups/encrypted --kind full --alert
```

上传范围严格是 `payload.cms` 与 `manifest.json`，不会上传明文数据库、恢复私钥或目录内其他文件。路径为 `实例/类型/批次/文件`；先上传密文并完整回读比对 SHA-256，再上传并回读清单作为发布标记。失败不记为成功；重试使用同一批次字节，不产生另一份逻辑备份。单批最多 256 MiB，超过限制明确失败。

同步持有本地备份任务锁，避免同时保留清理掉正在传输的文件。回执保存在私有备份目录，绑定实例、目的地摘要、批次和校验值。检查同时核对本地批次、异地回执、远端清单及密文存在性；完整副本最多 26 小时，删除记录最多 1 小时。检查不重新下载全部密文，不能代替定期远端解密与删除重放演练。异地保留周期须在存储端配置，工具不自动删除远端批次。

## 独立监控

`--alert` 才向操作员配置的 Webhook 发送通用健康状态：固定服务名、`full/ledger` 类型和 `healthy/needs_attention`，不含路径、端点、密钥或家庭资料。本轮没有向真实端点发送消息。完整与删除副本是独立信号，监控服务应分别检查失败以及超过预期未收到心跳；主机断网时本机无法通知，需依赖外部缺失心跳检查。

`deploy/systemd/` 增加异地同步和独立检查模板：完整副本每天上海时间 03:30，删除副本每小时 04/19/34/49 分，每类健康检查每 5 分钟。先安装原本地备份任务，再由运维配置端点、权限和监控。模板默认路径 `/opt/baba`、`/var/lib/baba`、`/etc/baba-backup` 需与实际主机一致；没有在当前环境安装或启用它们。

## 持续验证与发布资产

GitHub Actions 在 push/PR 运行 Python/HTTP/备份/客户端回归和 JavaScript 语法检查，真实支付、微信发送和模型配置关闭。手动运行工作流时另生成源码制品和校验和，不自动创建公开 Release。

```sh
python3 tools/release_bundle.py --output dist/release-0.2.1
# 在具备正式配置与 Android SDK 的打包机上，校验已有签名 APK 后一并打包：
python3 tools/release_bundle.py --output dist/release-0.2.1-android --apk /path/to/signed.apk
```

工作区必须干净。源码来自明确 Git 提交，只打包白名单代码、文档、客户端、模板和测试，不包含本机数据和密钥。ZIP 使用稳定顺序与时间戳，可重复生成相同字节；输出目录不可覆写。

固定资产名 `baba-source.zip`、可选 `baba-android.apk`、`release.json`、`SHA256SUMS`。元数据记录版本和 Git 提交；源码包不伪称安装包。附带 APK 前必须有 Android SDK `apksigner` 和 `aapt`、正式包名、匹配的版本号/代码和有效 APK 签名；工具拒绝仅改后缀的 ZIP。校验签名有效不等于核验发行者身份，正式分发还须核对预期签名证书。

当前 DCloud 标识、签名密钥、正式 Android/iOS 标识尚未配置，未生成正式安装包，也未核验最低系统版本或商店路径。真实安装与支付继续按用户要求暂缓；此工具不会创建假包或擅自发布。
