# 海报、家庭互动与账号安全

更新：2026-10-29。网页、HTML5+ 共用页面和小程序源码均提供入口；本轮使用合成账号、模拟微信及真实本机浏览器验收，没有进行真实微信发送、支付或真机验收。

## 通用准备海报

待产准备 → 分享清单 → 生成通用海报。输出 720 × 1100 的 PNG，包含九项通用生活用品、三类分组与公开模板二维码。网页提供下载和长按图片保存；小程序提供相册保存，需要本人授予相册权限。

海报不接受家庭快照作为绘制参数，不包含家庭名称、成员、日期、实际物品、备注、进度、徽章或私人分享令牌。二维码只打开 `/#template`，不授予加入家庭权限。二维码生成库随源码提供，带 MIT 授权说明，不依赖外部二维码图片服务。

选择“小程序码”时，服务端须显式启用 `WX_POSTER_ENABLED=1` 并配置 `WX_APP_ID`、`WX_APP_SECRET`。服务端向微信请求正式版 `pages/main/main` 的固定 `scene=template`，收到真实 PNG 才返回；失败提示改用网页二维码，不制作假小程序码。外部 HTTP 在数据库事务外执行，返回前复查会话。默认关闭，本轮仅模拟平台。

部署后的网页二维码使用实际访问来源，小程序二维码海报使用配置的服务来源。开发环境的 localhost 二维码只适合本机验证；需要手机扫描时必须先配置可访问的 HTTPS 服务。图片保存、转发后不能远程撤回；私密分享继续使用独立的限时链接。

## 家庭点赞与留言

家庭空间增加“看见彼此的小事”，只展示有可靠执行归属、仍保持完成状态、当前有权查看的任务和物品。待确认记录不展示为完成，不猜测旧记录的执行人。普通成员仍只看到其当前分工范围。

每项完成事实有独立互动 ID，绑定完成凭据和当前资源版本。撤销、重新完成或编辑资源后产生不同入口，旧互动不会重新挂到新记录。当前任务、健康和独立宝宝授权在每次读取及提交时重新检查；成员退出/转交、健康授权变化时清理失去范围的留言，下次调度清理其他过时内容。离开后再加入或撤权后再授权不恢复旧留言正文。

点赞是明确的开启/收回状态，每人每项最多一赞，不用切换操作模拟幂等。留言最多 300 字，每人每小时最多 20 次；使用原家庭命令恢复链路，丢响应重试保留同一请求号，避免重复留言。界面按文本显示，不能执行留言里的 HTML。

本人可删除自己的留言，统筹者可管理当前可见留言；妈妈角色不自动获得删除其他作者留言的权限。删除清空正文，不返还任何徽章或积分，也没有点赞排名。互动不进入公开分享或微信提醒。请勿在留言中填写健康资料，因为能查看此完成记录的家人可读留言。删除账号时清理本人互动及受影响家庭的互动正文；恢复备份清空旧互动，避免旧共享范围复活。

## 账号安全

网页设置/未加入家庭的欢迎页、小程序家庭页/欢迎页均提供“账号与安全”；登录页提供恢复码找回。

| 操作 | 本人验证 | 结果 |
|---|---|---|
| 修改密码 | 当前密码；小程序也可重新验证已绑定微信 | 设置 10—128 字符新密码，注销所有会话，废弃旧恢复码 |
| 生成/轮换恢复码 | 同上 | 生成高熵随机码，仅本次显示，旧码立即失效 |
| 忘记密码 | 账号 + 本人提前保存的恢复码 | 重设密码，注销所有会话，恢复码一次使用后作废；不自动登录 |
| 密码注销 | 当前密码并确认范围 | 沿用独立删除记录和健康资料清理 |
| 微信注销 | 重新获取的微信 code，服务端验证为当前账号已绑定身份，并确认范围 | 无需知道微信自动账号的随机密码；沿用同一删除事务 |

恢复码仅保存 SHA-256 摘要，不进入家庭状态、命令结果、日志或客户端持久存储。关闭弹层、退出、切换账号及进入后台时清理恢复码和验证表单。重新生成后丢失响应，可以用原验证方式再生成；修改/找回密码结果未知时，先尝试新密码登录，不自动重复安全操作。

微信 code 由服务端换取 AppID/openid，再与当前账号已绑定记录匹配；不会在安全验证时偷偷新绑、合并其他微信账号。外部验证返回后在同一写事务重新检查会话及 CSRF。仍担任任一家庭统筹时拒绝注销，须先转交并由对方接受。

未提前保存恢复码、又不能使用原微信身份时，本版没有短信、邮箱找回或人工绕过身份验证。此时不能声称仅凭账号名即可找回。恢复备份会清空旧恢复码和会话，需重新配置。

找回接口的错误不区分账号存在与否，IP 每 15 分钟最多 6 次。已登录安全验证每账号每 15 分钟最多 8 次；失败也占限流预算。所有响应禁止缓存。

## 接口与验收

新增 `GET /api/account/security`、`POST /api/account/password`、`POST /api/account/recovery-code`、匿名 `POST /api/account/recover`、`POST /api/account/delete-wechat`、登录后 `GET /api/poster/code`。

互动动作 `feedback.like/comment/delete` 走 `/api/action`，并沿用内容绑定幂等请求号。家庭快照中的 `feedback_feed` 已按当前用户范围筛选。

```sh
PYTHONDONTWRITEBYTECODE=1 python -m unittest discover -s tests
python tests/run_browser_community_accounts.py
```

浏览器环境与 [多端弱网验收](多端弱网验收.md) 相同。浏览器覆盖双账号互动、连续丢弃已保存响应后的唯一留言、文本转义、撤销完成后隐藏、可选模板、PNG 下载、旧会话失效、恢复码轮换与一次找回。小程序适配器覆盖重新验证、迟到回调、退出和后台清理。
