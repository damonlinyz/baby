# 知识策展、AI 用量与服务后台

更新：2026-10-29。本轮补齐此前清单未单列的四项软件缺口；系统管理员由服务端 `ADMIN_USER_ID` 指定，家庭统筹者不会自动拥有系统后台权限。没有调用真实模型、微信发送或支付服务。

## 知识元数据与封闭策展

系统管理员在“管理生活知识”中维护目标角色、适用阶段、适用地区、家人策展标记、来源 HTTPS 链接及发布日期、许可说明、适用人群/范围、生效和到期日。每次保存生成独立内容版本，记录实际编辑账号和时间，不允许客户端伪装审核人。

正文与版本包含上述字段；阅读页展示来源、许可、范围、编辑及有效期，来源不收费隐藏。一般生活编辑审核不等于医疗专业审校，`clinical=true` 仍拒绝发布。默认字段用于兼容旧版一般生活内容，不把旧来源自动宣称为已获转载许可；初始自编生活知识明确标为产品原创。

| 范围 | 规则 |
|---|---|
| 角色 | 仅返回 `target_roles` 包含本人当前角色的内容 |
| 家人策展 | 普通成员还须满足 `member_curated=true`；网页不提供自由关键词搜索入口，小程序继续使用封闭卡片 |
| 阶段 | `general` 为通用；其他阶段只根据本人当前有权查看、未暂停/归档的健康时间轴匹配，不查询隐藏健康日期来改变卡片 |
| 地区 | 每人、每家庭独立设置；留空仅通用，可输入 CN、CN-SH 等大写代码，不从时区或定位推断 |
| 有效期 | 生效日起至截止日当天有效，按北京时间日历日期；未到生效日、过期、撤回或医疗内容不交付 |

“阅读地区与范围”入口可修改个人地区。修改后刷新阅读与任务引用，并使该接收人的旧简报失效；切回旧地区不恢复已经清理的简报正文。

知识卡片打开时调用服务端取得当前版本，不直接显示页面缓存正文。任务关联知识、导出、简报及 AI 引用也按当前范围复核。撤回后再次点击旧卡片不会继续展示旧正文。服务端不返回范围外文章供前端自行隐藏。

AI 检索进一步限制为一般阶段素材，即使获得健康查看授权，也不根据其日期为模型选择孕周阶段素材；`health_read` 不等于同意把健康阶段透露给模型。历史回答、缓存交付和正在生成的回答仍复查角色、地区和当前引用，失效时不交付或计成功次数。

## AI 周期、用量与场景入口

网页 AI/购买权益入口、小程序 AI/家庭页提供“我的 AI 用量”。区分本人累计成功、有效处理中占额、最近 24 小时调用数及配置上限。失败和超期租约不占有效额度；删除历史不返还已完成次数。

绑定的 AI 周期分别展示问答和周简报总额、成功、占额与剩余，按家庭共享额度计算，不展示其他人的问题、答案或身份。未开始、到期、待本人启用和撤销明确区分；小程序补齐本人启用赠送 30 天周期的入口。用量展示不代表已经完成真实收费或供应商成本评测。

任务详情和物品编辑增加场景化问 AI 入口，仅向统筹者开放。它们只预填通用的步骤/分工或盘点/预算问题，不复制事项名称、健康信息、备注或家庭成员。本人仍须点击“发送”，不会因打开详情而自动调用模型。

## 本人问题工单

已登录用户即使没有加入家庭，也能从“问题与反馈”提交和查看工单；AI 入口另提供回答问题分类。仅保存本人手动填写的标题、分类与最多 1000 字说明，须确认交给系统管理员处理；不自动附加家庭快照、健康日期、日志或 AI 对话。

工单绑定本人和原请求号；同一内容重试返回同一工单，改动内容不能借用旧请求号。每账号每小时最多新建 5 条。丢响应时可在同一表单核对，或者先打开“我的问题”；不做跨重启离线补发。

管理员只能查看用户明确提交的工单，不能由此打开其家庭资料或私人问答。可回复并标记待处理、处理中、已解决，修改绑定版本，迟到回复不能覆盖已经撤回的工单。回复在产品内查看，不自动发送微信、邮件或外部消息。

本人可撤回并清空标题、说明及管理员回复，其他家庭成员和家庭统筹者不能查看或撤回。最近处理后的 180 天到期清理正文；读取和回复前也整理过期记录。删除账号清理本人工单；恢复旧备份清空全部旧工单，防止已撤回正文复活。本人数据导出包含当前有效的本人问答历史与本人问题记录，不含他人的内容。

关闭/退出及前台授权复核清理私密视图；未选择家庭时也复核会话，失效后不会继续显示旧工单。

## 系统队列与安全重排

系统管理员网页设置增加“队列与运行状态”。按 Outbox、站内提醒、外部投递、AI 请求展示状态数量、待处理记录创建年龄及最多 100 项待核对记录。只显示队列 ID、家庭 ID、状态、版本、时间和尝试数，不含家庭称呼、成员、健康日期、通知标题或问答正文。

只有 `failed` 的站内时间轴 Outbox 可以人工重新排队。操作者须确认已核对失败原因；服务端检查当前版本、原孕次修订、暂停/结束/归档和原接收人的当前授权。失效来源直接取消并提交该状态；有效来源重新排队，投递时再次鉴权。沿用稳定通知 ID，不重复创建站内消息；网页丢响应时也保留原重排请求号核对。

每条记录最多人工重排三轮，每轮沿用原有自动尝试上限；人工操作带规范化内容摘要的请求号，重试不重复重排。管理操作记录在全局管理审计，不把私密通知的重排时间作为普通家庭动态展示。

外部微信投递无论失败或结果未知，均不能在此强制重发；AI 请求和普通提醒也不提供绕过去重/授权的“重试所有”按钮。本轮没有执行任何真实外发。此后台是软件队列可观测能力，未宣称已具备生产 SLA、完整 API 指标或支付渠道对账服务。

## 接口与复验

|---|---|
| GET `/api/knowledge?family_id=...&id=...` | 当前成员及阅读范围；返回当前正文 |
| 动作 `knowledge.preferences` | 本人的家庭阅读地区 |

| GET/POST `/api/support` | 本人列表/明确提交 |
| POST `/api/support/withdraw` | 本人版本校验撤回 |
| GET/POST `/api/admin/support` | 系统管理员查看/回复 |
| GET/POST `/api/admin/operations` | 系统管理员队列投影/站内安全重排 |
