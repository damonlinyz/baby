A FEW SMALL ANSWERS
开始前，你可能想知道。
为什么现在还不能下载？＋
只有真实的、经过签名与版本校验的安装包发布到 GitHub Releases 后，下载按钮才会开放。源码和打包工具已经存在，并不等于安装包已经发布。
下载后怎样开始使用？＋
Android 版本发布后，下载安装包，按系统提示完成安装。打开 App，填写你部署或受邀使用的 HTTPS 服务地址，再登录并创建家庭或使用家人的邀请码加入。尚未提供公共托管服务地址。
GitHub Pages 会保存家庭健康资料吗？＋
不会。这是静态产品与下载页面，不提供账号登录，也不连接家庭数据库。实际使用时，资料保存在你所使用的应用服务中，并按当前授权共享。
为什么分享链接不会直接加入家庭？＋
通用分享用于预览准备模板，加入家庭仍需要独立邀请。健康资料和宝宝资料也需要本人或监护人的单独授权。
它可以代替医生安排检查吗？＋
不可以。它用于生活分工、物品准备与记录已确认的安排，不作诊断，也不会自行决定检查、用药或医疗时间。
下载慢或遇到使用问题怎么办？＋
GitHub 在不同网络下的访问情况可能不同，可以稍后重试或查看对应版本的发布记录。使用问题可在 App 的“问题与反馈”中提交，回复在产品内查看。
